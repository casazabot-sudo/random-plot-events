Random Plot Events for SillyTavern
​Расширение для SillyTavern, генерирующее случайные сюжетные события в процессе ролевой игры.
​Возможности
​Настраиваемый случайный интервал: по умолчанию 20–30 сообщений (каждый раз выбирается новое число).
​10 Категорий: Тайны, Осложнения, Встречи, Опасность, Социальные конфликты, Улики, Возможности, События окружения, Последствия поступков, Романтическое развитие.
​Защита от повторов: Исключает категории, выпадавшие в течение последних 3 событий.
​3 Уровня интенсивности: Ненавязчивые, сбалансированные или драматичные происшествия.
​Принудительный вызов: Кнопка для запуска события в следующем сообщении ИИ.
​Сохранение контекста: Инструкция требует соблюдения лора и запрещает ИИ управлять персонажем игрока.
​Установка
​Создайте папку random_plot_events внутри вашей директории SillyTavern:
public/scripts/extensions/third-party/random_plot_events
​Перенесите в эту папку созданные файлы (manifest.json, index.js, style.css, README.md).
​Запустите или обновите SillyTavern. Расширение появится в меню настроек расширений.
